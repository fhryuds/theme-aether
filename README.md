# Aether 苍穹

一款为个人博客打造的 Halo 2.x 主题，清新青绿配色、杂志式排版、文档级阅读体验。

## ✨ 特性

- **清新青绿配色**：柔和光晕背景 + 玻璃拟态卡片 + 精致阴影
- **杂志式首页**：双栏错落卡片布局（首篇大图 + 错落网格），可选均匀网格 / 纯净列表
- **首页右侧边栏**：个人简介、文章分类、归档入口、标签云
- **文档级文章阅读**：三栏布局（左文章列表 + 中正文 + 右目录），标题打字机特效
- **自动目录（TOC）**：从正文 h2/h3/h4 自动提取层级目录，滚动高亮当前章节
- **全站搜索**：顶栏放大镜 / `Ctrl + K` / `/` 唤起搜索弹层，实时过滤标题、摘要、分类、标签，关键词高亮，支持空格分隔多关键词与 ↑↓ 键盘选择，无需安装任何插件
- **明暗模式**：太阳/月亮图标切换，跟随系统、记忆偏好、防闪烁
- **响应式**：移动端抽屉导航（含搜索入口），侧边栏自动隐藏
- **可配置**：强调色、站点名称、版权年份、备案号、个人简介、社交链接等

## 📦 安装

1. 下载 `theme-aether.zip` 安装包；
2. Halo 后台 → **主题** → **主题管理** → **安装主题**，上传 zip；
3. 安装完成后**启用**主题；
4. 在「主题设置」中配置强调色、站点名称、备案号等。

## ⚙️ 配置项

| 分组 | 配置项 | 说明 |
|------|--------|------|
| 基础设置 | 强调色 | 主题点睛色（默认青绿 `#0d9488`） |
| 基础设置 | 个人简介 | 首页 Hero 与侧边栏签名 |
| 基础设置 | 头像地址 | 侧边栏头像（留空用首字母） |
| 基础设置 | GitHub 链接 / 社交链接 | 侧边栏社交图标 |
| 基础设置 | 站点名称 | 页脚版权位置（留空用站点标题） |
| 基础设置 | 版权年份 | 页脚 © 后的年份 |
| 基础设置 | 备案号 / 公安备案号 | 页脚展示 |
| 布局设置 | 首页布局 | 双栏错落 / 均匀网格 / 纯净列表 |
| 布局设置 | 首页按发布时间严格排序 | 默认开启。开启后首页严格按 `publishTime` 倒序，「最新发布」一定是真正最新的一篇；关闭则恢复 Halo 默认排序（置顶 / 优先级高的文章排前面） |
| 布局设置 | 首页显示摘要 | 是否显示文章摘要 |
| 布局设置 | 文章显示目录 | 是否显示左侧目录 |

## 🔍 搜索说明

搜索为**纯前端实现**，不依赖 `plugin-search-widget` 插件，也不占用后端接口：

- 主题在页面底部渲染一份隐藏索引（`postFinder.listAll()` 的全部文章标题、摘要、分类、标签）；
- 输入关键词后由 `main.js` 在本地过滤，多个关键词用空格分隔（AND 语义），命中的词以强调色 `<mark>` 高亮；
- 结果按发布日期倒序，最多展示 30 条；
- 检索范围为**标题 / 摘要 / 分类 / 标签**，不含正文全文。文章量极大（数千篇以上）时索引体积会变大，可考虑改装官方 `plugin-search-widget` 插件做全文检索。

## 🛠 开发环境

- **Halo ≥ 2.20.0**（模板引擎 Thymeleaf）
- 无需前端构建工具，纯静态 HTML/CSS/JS，开箱即用

## 📂 目录结构

```
theme-aether/
├── theme.yaml                 # 主题元数据
├── settings.yaml              # 主题设置表单
├── screenshot.png             # 预览图
├── i18n/                      # 国际化
├── templates/
│   ├── layout.html            # 页面布局契约
│   ├── index.html             # 首页
│   ├── post.html              # 文章详情（三栏）
│   ├── page.html              # 独立页面
│   ├── archives.html          # 归档
│   ├── categories.html        # 分类集合
│   ├── category.html          # 分类归档
│   ├── tags.html              # 标签集合
│   ├── tag.html               # 标签归档
│   ├── search.html            # 搜索（独立页面兜底模板）
│   ├── error/error.html       # 错误页
│   ├── common/                # 公共片段（header/footer/sidebar/drawer/search 等）
│   └── assets/                # 静态资源（css/js）
```
